# Open Anchoring Quest (OpAQ) — Static Dashboard

A static, interactive HTML dashboard for the **Open Anchoring Quest (OpAQ)**, an ever-growing open dataset on anchoring effects. This is a re-implementation of the original R Shiny app (see `ShinyApp/app.R`) as a single-page static site, restyled in a light-blue, sans-serif design inspired by the [FLoRA Explorer](https://forrt.org/flora-explorer/).

The site is hosted with **GitHub Pages**.

## Features

- **Summary** – overview stats (references, trials, participants, items) and a study-overview stacked chart.
- **Effect Sizes** – forest plot and funnel plot of anchoring effects (REML meta-analysis), with click-to-highlight interaction in the effects table.
- **Moderators** – explore the relationship between moderators (published, prereg, age, gender, anchor distance, etc.) and anchoring effect sizes.
- **Reliabilities** – average inter-item correlations by study and score type, with score definitions.
- **Anchor Distance** – scatter of relative anchor distance vs. relative adjustment across studies.
- **Dataset** – searchable, sortable, paginated view of the full dataset (~90k rows) with a download link.
- **Literature** – overview of anchoring research, including open-data, eligible, and included flags.
- **References / About** – citations, author contributions, and the call for data.

## Data

Data is saved from the original OSF project: <https://osf.io/ygnvb/>

- `Datasets/opaq_70a.csv` – the full item-level dataset (original).
- `Datasets/opaq_results.xlsx` – reliabilities and effect-size sheets.
- `Datasets/OpAQ_AnchoringDatasets.xlsx` – list of anchoring datasets.
- `data/*.json` – pre-computed, processed data consumed by the dashboard.

The JSON files were generated by `precompute.R`, which replicates the analysis in `ShinyApp/app.R` (meta-analysis via `metafor::rma.mv`, Egger's test, moderators, reliabilities, and anchor-extremeness calculations).

## Running locally

Serve the repository with any static file server (the data is fetched via `fetch`, so a server is required):

```sh
python -m http.server 8000
```

Then open <http://localhost:8000/>.

## Build

To regenerate the `data/*.json` files from the raw data, run in R:

```sh
Rscript precompute.R
```

Requires the R packages `metafor`, `openxlsx`, `dplyr`, `jsonlite` (and `meta` for Egger's test).
